

\section{Постановка задачи}
\textbf{Цель.}
Создание базы данных для предметной области <<Индивидуальный учет рациона поголовья коров>>.\\

\textbf{Задачи.}
\begin{itemize}
    \item Составление описания предметной области, постановка целей создания базы данных.
    \item Выделение сущностей и их атрибутов из предметной области, составление ER-диаграммы и схемы связи объектов.
    \item Создание таблиц для последующей генерации базы данных, составление схемы базы данных.
    \item Генерация базы данных и заполнение ее данными.
    \item Написание 9 запросов к созданной базе данных, выданных преподавателем.
\end{itemize}
