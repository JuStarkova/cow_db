


\begin{abstract}
    Курсовая работа представляет собой разаработку базы данных для предметной области <<Индивидуальный учет рациона поголовья коров>>. Основная проблема заключалась в необходимости хранения индивидуальных характеристик коров, хранения данных о суточном рационе каждой коровы. В ходе работы было составлено описание предметной области на основе открытых литературных источников, спроектирована, создана и заполнена база данных, написано 9 запросов для созданной базы данных. Для взаимодействия с базой данных использовалась командная строка PostgreSQL, для заполнения данными --- среда VS Code. Полученная система может быть использована фермерским хозяйством, содержащим дойных коров, для управления данными о питании и лактациях коров.
\end{abstract}
